# Методологія порталу

> 🇺🇦 Українська версія | 🇬🇧 [English version](./en/methodology.md)

Цей документ описує **роль центрального хаба** `lectures/docs/` та зв'язок між методичними статтями. Деталі оцінювання та протоколу ШІ — у окремих документах (посилання нижче), **без дублювання їхнього змісту**.

---

## 1. Призначення порталу

Портал об'єднує:

1. **Дисциплінарні курси** (зовнішні GitHub Pages: Web, Blockchain, C++, Java) — лише посилання в [`index.md`](./index.md).
2. **Локальні курси та дослідницькі траєкторії** — повний контент у підпапках (`gdl_in_logistics/`, `nlp_signal_noise/`, тощо).
3. **Методичну роботу** — статті 00–15 у корені `docs/`.
4. **Active Projects** — `k8s_llm/`, `urban_evac_sim/`.

Кожен локальний курс має власний [`methodology.md`](./gdl_in_logistics/methodology.md) з траєкторією модулів; цей файл описує лише **хаб-рівень**.

## 3. НМК на рівні курсу

Для кожної локальної підпапки з `index.md`:

| Артефакт | Призначення |
|----------|-------------|
| [`DISCLAIMER.md`](./DISCLAIMER.md) (хаб) | Повний текст; у лекціях — коротка вставка |
| `{курс}/methodology.md` | Траєкторія модулів, посилання на `study_materials` / `material_study` |
| `{курс}/sources.md` | Реєстр першоджерел `[1]…[N]` |
| `{курс}/exam.md` | Опційно — лише якщо курс має іспитовий пул |

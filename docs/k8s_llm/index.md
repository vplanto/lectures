**Мета роботи:** Навчити Велику Мовну Модель (LLM) виконувати роль **SRE-асистента** для діагностики відмов та FinOps-оптимізації.

##  Робочі Дані (Dataset)

* **`obfuscator.py`**: Скрипт для очищення чутливих даних. (У репозиторії лежить Template-версія. Робоча версія запускається Supervisor-ом).
* **`/data/01_clean_pool`**: Набір безпечних, обфускованих логів для вашої роботи.

### Характеристика Джерел (Sites)

Ми використовуємо дані з трьох різних середовищ, кожне з яких має свою специфіку:

1.  **Site Alpha (`site-alpha`):**
    * **Тип:** High-Performance Cluster.
    * **Особливості:** Дуже потужні вузли (128 CPU / 750GB RAM).
    * **На що дивитися:** Ідеальний полігон для FinOps. Тут багато прикладів **Infrastructure Mismatch** (дисбаланс використання ресурсів) та **Missing Limits** у системних сервісів.

2.  **Site Beta (`site-beta`):**
    * **Тип:** Unstable Production.
    * **Особливості:** Кластер під навантаженням з історією збоїв.
    * **На що дивитися:** Основне джерело реальних помилок. Шукайте тут **OOMKilled** (сервіс `consul`) та **CrashLoopBackOff**.

3.  **Site Gamma (`site-gamma`):**
    * **Тип:** Standard Workload.
    * **Особливості:** Типова мікросервісна архітектура.
    * **На що дивитися:** Використовуйте як базу для **синтезу** (Error Injection), оскільки тут конфігурації відносно чисті.

##  ML Stack: Рекомендації для Тренування

Для виконання дипломної роботи рекомендується використовувати наступний стек:

### 1. Базові Моделі (Base Models)
* **Llama 3 8B (Instruct):** *Рекомендований вибір №1.* Найкраща якість генерації JSON.
* **Mistral 7B (v0.3):** Гарна альтернатива з великим контекстним вікном.

### 2. Бібліотека для навчання
Настійно рекомендується використовувати **Unsloth** (https://github.com/unslothai/unsloth).
* **Чому:** Прискорює навчання у 2-5 разів, дозволяє тренувати модель на безкоштовних GPU (T4).

### 3. Середовище виконання
* **Google Colab (Free/Pro):** Оптимально для старту.
* **Kaggle Kernels:** Альтернатива з безкоштовними GPU T4 x2.

##  Алгоритм Роботи

1.  **Підготовка Даних (Тиждень 1):**
    * Отримати дані з `/01_clean_pool`.
    * Виконати інструкції з Файлу 04 (Gap Analysis & Synthesis).
    * Сформувати `train.jsonl` (мінімум 50-100 якісних прикладів).

2.  **Fine-Tuning (Тиждень 2):**
    * Використати Unsloth для донавчання моделі на створеному датасеті.

3.  **Валідація (Тиждень 3):**
    * Використати методологію з Файлу 05.
    * Порівняти відповіді Base Model та вашої Fine-Tuned Model (метрики Math Consistency та JSON Valid Rate).

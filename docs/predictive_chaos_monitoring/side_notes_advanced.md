### 1. Гіпотеза Глікемичної Персистентності (До Блоку 1: Показник Херста)

При моніторингу метаболічних станів (гіпоглікемія) важливо розуміти, чи є падіння показника випадковим шумом (White Noise), чи частиною довгострокової пам'яті системи.

**Математична модель:**
Для часового ряду рівня глюкози $G_t$ обчислюється відношення $R/S$:
$$\frac{R(n)}{S(n)} = C \cdot n^H$$
Де:
* $R(n)$ — розмах накопиченого відхилення.
* $S(n)$ — стандартне відхилення.
* $H$ — показник Херста.

**Side Note для лекції:**
* **$H \approx 0.5$ (Random Walk):** Реакція організму на цукор є хаотичною (небезпечний стан, непередбачуваність).
* **$H > 0.7$ (Trend Reinforcing):** Система має "пам'ять". Це дозволяє предиктивно вводити вуглеводи за 15-20 хвилин до критичного піку гіпоглікемії під час веслування (Rowing).

### 2. Біфуркації Навантаження Інвертора (До Вступу: Теорія Хаосу)

Система енергонезалежності (Deye Inverter + Solar) при досягненні граничних значень потужності $P_{max}$ може демонструвати поведінку, аналогічну до логістичного відображення.

**Рівняння фазового переходу:**
$$x_{n+1} = \lambda x_n (1 - x_n)$$
Де $x_n$ — нормалізоване навантаження на шину DC, а $\lambda$ — коефіцієнт нелінійності споживання (одночасне ввімкнення реактивних навантажень).

**Практичне застосування:**
При $\lambda > 3.56$ система входить у режим детермінованого хаосу. В SRE-практиці це момент, коли стандартні "threshold alerts" (CPU > 80% або Load > 5kW) стають марними, оскільки система коливається між декількома станами рівноваги перед повним відключенням (Blackout).

### 3. Реконструкція Термальних Аномалій (До Блоку 3: Anomaly Detection)

Для захисту травмованих ділянок (руки, чутливість до холоду) та при холодовій алергії, важливо детектувати аномальні зміни мікроклімату на Edge-рівні (ESP32).

**Алгоритм Reconstruction Error ($\mathcal{L}$):**
Використовується Autoencoder або LSTM для стиснення та відновлення вектора станів середовища $v = [T, humidity, wind\_chill]$.
$$\mathcal{L}(v) = \| v - f_{\theta}(g_{\phi}(v)) \|^2$$

**Side Note:**
Якщо $\mathcal{L}(v) > \text{Dynamic\_Threshold}$, система активує превентивний обігрів ще до того, як фізичні датчики зафіксують абсолютне падіння температури. Це мінімізує "Household Latency" та зберігає когнітивний ресурс для High-load задач.

### 4. Attention Gate як Фільтр Когнітивного Навантаження (До Блоку 2: Attention)

Для Lead-інженера з постійним перемиканням контексту, механізм Attention є математичною моделлю ідеального Dashboard.

**Scaled Dot-Product Attention:**
$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

**Аналогія для SRE:**
* $Q$ (Query) — поточний фокус інженера (наприклад, "Incident Response").
* $K$ (Keys) — тисячі метрик системи.
* $V$ (Values) — реальний стан інфраструктури.

**Side Note:**
Система моніторингу повинна працювати як Multi-Head Attention, підсвічуючи лише ті метрики (High-load, Capacity Planning), які мають найбільшу "вагу" (Attention Weight) для поточного контексту, ігноруючи фоновий "шум".

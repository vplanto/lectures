# Синтетичні датасети для предиктивного моніторингу

Цей проект реалізує генерацію та аналіз двох синтетичних датасетів для тестування системи предиктивного моніторингу:
- **Controlled Chaos**: Логістичне відображення з інжектованими аномаліями
- **Pure Random**: Випадкове блукання (Random Walk)

## Структура проекту

- `dataset_generators.py` - Генератори синтетичних датасетів
- `time_series_analyzer.py` - Математичний аналіз (Херст, ADF, ACF)
- `lstm_predictor.py` - LSTM модель для предиктивного тестування
- `main_analysis.py` - Головний скрипт для виконання повного аналізу
- `requirements.txt` - Залежності проекту

## Встановлення

```bash
pip install -r requirements.txt
```

## Використання

Запустіть головний скрипт:

```bash
python main_analysis.py
```

Скрипт виконає:
1. Генерацію обох датасетів
2. Математичний аналіз (показник Херста, ADF-тест, ACF)
3. Навчання LSTM моделей
4. Обчислення помилок реконструкції
5. Візуалізацію результатів

## Результати

## Технічні деталі

### Controlled Chaos
- Логістичне відображення: x_{n+1} = r * x_n * (1 - x_n), r = 3.9
- Білий шум: ε ~ N(0, 0.01)
- Аномалії: 3-5 точок зі збільшенням значення на 50%

### Pure Random
- Випадкове блукання: X_t = X_{t-1} + ε_t
- Шум: ε_t ~ N(0, 0.1), i.i.d.

### LSTM Модель
- Розмір вікна: 60
- Прихований шар: 50 нейронів
- Кількість шарів: 2
- Поріг аномалій: μ + 3σ

# Практичні семінари: Аналіз часових рядів та предиктивний моніторинг

Цей документ описує 5 практичних семінарів для курсу з аналізу часових рядів та предиктивного моніторингу.

## Структура семінарів

### Семінар 1: «Павутинна діаграма хаосу» (Cobweb Plot Lab)
**Файл:** `seminar_01_cobweb_plot.py`

**Мета:** Візуалізувати перехід від стабільності до хаосу в логістичному відображенні

**Що робить:**
- Побудова павутинної діаграми (cobweb plot)
- Експериментальне знаходження точок біфуркації
- Візуалізація 2-циклу, 4-циклу та хаосу
- Аналіз стабільності нерухомих точок

**Запуск:**
```bash
python seminar_01_cobweb_plot.py
```

**Результат:** Графік `seminar_01_cobweb_plot.png` з павутинними діаграмами для різних значень параметра r

---

### Семінар 2: «Сліпе тестування пам'яті» (Hurst Blind Test)
**Файл:** `seminar_02_hurst_blind_test.py`

**Мета:** Навчити відрізняти випадковий шум від сигналу з пам'яттю за допомогою показника Херста

**Що робить:**
- Генерація трьох анонімних датасетів:
  - Чисте випадкове блукання (H ≈ 0.5)
  - Антиперсистентний ряд (H < 0.5)
  - Метрика з реальною пам'яттю (H > 0.7)
- R/S аналіз для обчислення показника Херста
- Візуалізація в логарифмічних координатах

**Запуск:**
```bash
python seminar_02_hurst_blind_test.py
```

**Результат:** Графік `seminar_02_hurst_blind_test.png` з аналізом всіх трьох датасетів

---

### Семінар 3: «Ручний вентиль LSTM» (Hydraulic Gates Sandbox)
**Файл:** `seminar_03_lstm_gates.py`

**Мета:** Демостифікація роботи LSTM через покроковий прорахунок стану комірки

**Що робить:**
- Ручна реалізація LSTM комірки
- Моделювання сценарію інциденту (нормальний тренд → сплеск)
- Демонстрація роботи Forget, Input та Output gates
- Візуалізація потоку градієнта (вирішення проблеми зникаючого градієнта)

**Запуск:**
```bash
python seminar_03_lstm_gates.py
```

**Результат:** 
- `seminar_03_lstm_gates.png` - сценарій інциденту
- `seminar_03_gradient_flow.png` - потік градієнта
- `seminar_03_interactive_experiment.png` - інтерактивні експерименти

---

### Семінар 4: «Спектральна чистка» (FFT Denoising)
**Файл:** `seminar_04_fft_denoising.py`

**Мета:** Навчитися виділяти аномалії, «відсікаючи» сезонність у частотній області

**Що робить:**
- Генерація даних з денною та тижневою сезонністю
- Застосування FFT для знаходження домінуючих частот
- Видалення сезонних частот зі спектру
- Зворотне перетворення (IFFT) для отримання очищеного сигналу
- Виявлення «тихої» аномалії, замаскованої під сезонність

**Запуск:**
```bash
python seminar_04_fft_denoising.py
```

**Результат:** Графік `seminar_04_fft_denoising.png` з порівнянням оригінального та очищеного сигналу

---

### Семінар 5: «Динамічний кордон» (Anomaly Detection Lab)
**Файл:** `seminar_05_anomaly_detection.py`

**Мета:** Порівняти ефективність статичних та динамічних порогів (thresholds)

**Що робить:**
- Реалізація пайплайну: Sliding Window → LSTM → Reconstruction Error
- Навчання моделі на нормальних даних
- Тестування на рядах із «тихими» аномаліями
- Порівняння статичного порогу (абсолютні значення) vs динамічного порогу (помилка реконструкції)
- Візуалізація виявлення аномалій через правило 3σ

**Запуск:**
```bash
python seminar_05_anomaly_detection.py
```

**Результат:** Графік `seminar_05_anomaly_detection.png` з порівнянням методів виявлення аномалій

## Навчальні цілі

Після проходження всіх семінарів студенти зможуть:

1. **Розуміти хаос та біфуркації:**
   - Візуалізувати перехід до хаосу
   - Розпізнавати зони турбулентності

2. **Аналізувати пам'ять процесів:**
   - Обчислювати показник Херста
   - Відрізняти випадковий шум від сигналу з пам'яттю

3. **Розуміти роботу LSTM:**
   - Контролювати інформаційний потік через вентилі
   - Вирішувати проблему зникаючого градієнта

4. **Застосовувати спектральний аналіз:**
   - Видаляти сезонність через FFT
   - Виявляти аномалії в частотній області

5. **Виявляти аномалії:**
   - Використовувати динамічні пороги
   - Застосовувати помилку реконструкції для виявлення аномалій
